# Responsive Landing Page — Task 01

A responsive and interactive landing page created for a frontend development task.

## Features

- Fixed navigation bar
- Navigation changes style after scrolling
- Hover effect on menu items
- Active navigation item based on the current section
- Smooth scrolling
- Responsive layout for desktop, tablet and mobile
- Mobile hamburger menu
- Modern cards, gradients and glass-style UI
- No external libraries or frameworks

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## How to Run in VS Code

1. Extract the ZIP file.
2. Open the extracted `Responsive_Landing_Page_Task01` folder in VS Code.
3. Open `index.html`.
4. Right-click `index.html` and select **Open with Live Server** if you have the Live Server extension.
5. If Live Server is not installed, you can also open `index.html` directly in a browser.

## Task Requirements Covered

The navigation menu is fixed and remains visible while scrolling.
Its background and shadow change when the page is scrolled.
Each navigation item has a hover effect.
JavaScript is used for scroll detection, active-section highlighting and mobile navigation.
